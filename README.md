# Life Agent

Life Agent — мой личный проект для спокойного и последовательного ведения
повседневных данных о себе. Я разрабатываю его для собственного использования:
хочу собирать важные события дня в одном месте, тратить на это минимум времени и
со временем получать полезные выводы на основе своей истории.

## Зачем

Данные о питании, сне, активности, самочувствии и привычках обычно разбросаны по
разным приложениям или вообще нигде не фиксируются. Life Agent должен объединить
их в единый персональный журнал с простым вводом и разумной автоматизацией.

Главная цель — сначала научиться надёжно собирать факты, а затем использовать их
для персонального анализа: замечать закономерности, лучше понимать влияние
режима и принимать более осознанные бытовые решения.

## Возможности

В проект входят или планируются:

- учёт питания с собственными продуктами, блюдами и обычными порциями;
- отметки самочувствия с временем и комментарием;
- фиксация приёма лекарств и добавок;
- быстрые повседневные заметки;
- автоматический импорт доступных показателей сна, пульса, активности и веса;
- синхронизация личной истории между приложением и собственным хранилищем;
- будущий персональный агент для поиска закономерностей и работы с накопленными
  данными.

## Принципы

- Android-приложение — основной интерфейс.
- Ручная запись должна занимать несколько секунд.
- Автоматизация не должна создавать неподтверждённые факты.
- История принадлежит владельцу и остаётся под его контролем.
- Сначала качество и надёжность данных, затем аналитика и рекомендации.

Life Agent не является медицинским устройством и не заменяет врача.

## Текущее состояние

Проект находится в ранней активной разработке. Исследовательская и базовая
техническая подготовка завершена. Первый интерактивный интерфейс
Android-приложения уже собран: доступны светлая и тёмная темы, быстрый ввод,
справочники и экраны будущих подключений. Пока приложение работает с
демонстрационными данными; следующим этапом станет локальное хранение событий.
Публичного релиза пока нет.
